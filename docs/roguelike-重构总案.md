# Roguelike 重构总案

> 本文是「COIN RUSH → Roguelike」就地改造的总纲：目标、边界、玩法骨架、里程碑与引擎增件次序。
> 维护方式：讨论定案即回填本文；只写已批准的方向与次序，细节以代码与提交记录为准。

## 一、目标与边界

- **目标**：把 COIN RUSH（限时收币）就地改造为俯视角单屏 Roguelike（打怪升级生存）。
- **边界**：
  - **就地改造**，不新建仓库——复用现有外壳、场景框架、引擎子模块、测试与素材管线；
  - **main 冻结**：main 永远是历史基线，不再接受任何新提交；
  - **全部工作在 develop**：功能、修复、引擎升级均先落 develop；交付按 `develop → test → production` 单向流动（见 `docs/开发流程.md`）；
  - 引擎改动一律走「引擎仓提交 → 游戏仓子模块指针更新」的两仓舞蹈；引擎升级单独成笔提交，不与业务混提。

## 二、玩法骨架（已批准）

- **视角**：俯视角单屏（无滚动地图）。
- **操作**：WASD 移动（左右移动时水平翻转朝向）；战斗为**自动攻击**——每 `attack_cooldown` 秒对攻击范围内最近怪物自动出手（范围内无怪物不出手），无需攻击键（原 J 挥击已退役）。
- **敌人**：从屏幕边缘刷新；三种变体（史莱姆 / 哥布林 / 骷髅，外观+数值分化）等权随机；持续增援；强度随局内时间增强。
- **成长**：击杀掉落经验宝石 → 拾取积累 → 升级；M1 升级自动加属性，M2 升级改为三选一卡牌。
- **结束**：HP 归零 → 结束结算；R 重开 / M 回主菜单。
- **存档**：由「最高分」升级为「最佳战绩」。

## 三、里程碑

| 里程碑 | 内容 | 状态 |
| --- | --- | --- |
| **M1 战斗骨架** | WASD 移动 + 自动攻击（自动索敌/挥击表现）；怪物三变体边缘刷新 / 持续增援 / 随局内时间增强；经验宝石与拾取升级（自动加属性）；HP 与结算（R / M）；最佳战绩存档 | 进行中：引擎件（Vec2 / 输入系统 / 实体增强）与战斗骨架（自动攻击、三怪物变体、0x72 素材换血）已落地；升级与战绩待做 |
| **M2 三选一** | 升级时弹出三选一卡牌（升级选项池），选牌后继续 | 待开工 |

| **M4 验收发布** | 合 test → 观星台 → 合 production → tag `v0.1.0` → 打包 zip；exe 与发布产物不入 git | 待开工 |

## 四、引擎增件次序（与引擎 ROADMAP 对齐）

1. **Vec2 + 输入系统 + 实体增强**（已落地）：`engine/math/Vec2.h`（header-only）、动作映射 / 改键 / 边沿检测输入系统、Entity 增强（水平翻转 / 动画帧区间 / 最近邻采样）；
2. **粒子 + 相机震屏**（M3 拉动）；
3. **资源管理器**（纹理 / 字体统一加载与缓存）；
4. **远期 3D 一跳**：渲染抽象层 + SDL_GPU 后端（按引擎 ROADMAP 红线二 / 三的姿势）。

> 次序原则：每项引擎件都由 M1 ~ M4 的实际需求拉动，不提前做抽象（引擎 ROADMAP「游戏驱动、小步走」）。

## 五、发布策略（摘要）

- 发布节点 = tag（`v0.x.y`）；打包脚本产出可运行 zip（本地归档，日后可传 GitHub Releases）；
- exe 与发布产物一律不入 git；分支职责与发布细则见 `docs/开发流程.md`。
