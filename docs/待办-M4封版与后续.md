## 二、M4 · 封版待办

> 方向已获用户批准，按下列顺序执行；未完成前不进入 M5。

### 1. 护盾观察项修复

- **问题**：死亡惩罚失去技能时，该技能对应的**主动效果**仍可能残留。
- **规则**：
  - 失去技能时**清空其对应的主动效果**——例如失去护盾术 → 立即清空当前护盾 buff；
  - 减速 / 冻结等**减益不受影响**（只清理由「被失去技能」产生的主动增益）。
- **测试**：补单测，落在 `respawn` 或 `attack_element` 套件（按实际归属选择）。
- **完成判据**：构造「持有护盾 → 死亡丢失护盾术 → 复活」场景，断言护盾值为 0；
  减益（减速 / 冻结）状态不被误清。

### 2. 合入 production 与打 tag

- `test` → `production` **快进合并**（当前两者为直系关系，预期无冲突）；
- 打 **annotated tag `v0.1.0`**，附发布说明（2D 阶段成型、M3 内容、已知说明）；
- 推送 `production` 与 tag；
- 推送策略：快进；直连失败时用一次性代理 `-c http.proxy=http://127.0.0.1:7897`；**禁止 force**；
- 若出现非快进：**停止并报告**，不做任何强制推送。

### 3. 打包脚本 `tools/package.ps1`

- 流程：按 `x64-release` 预设构建 → 收集产物 → 压缩为
  `dist/RogueArena-v0.1.0-win64.zip`；
- 收集内容：
  - `GameDev.exe`（游戏主程序）；
  - **4 个运行时 DLL**：`SDL3.dll`、`SDL3_image.dll`、`SDL3_ttf.dll`、`SDL3_mixer.dll`；
  - `assets/`（素材）；
  - `config/`（配置）；
  - `玩家说明.txt`（当前仓库尚无此文件，打包前需编写）。
- **产物不入 git**：已核实当前 `.gitignore` **没有** `/dist/` 规则，需在脚本落地时补上 `/dist/`。
- **完成判据**：zip 解压后可直接运行；目录结构与 git 忽略规则均正确。
