- **成长**：商店（金币购买**九项强化**）、法术（升级三选一，**六种自动施法**）；
- **表现与战斗**：粒子 / 震屏、**双 Boss**、**空格闪避**（冲刺 + 无敌帧 + 残影）；
- **存档**：最佳战绩。

## 二、M4 · 封版完成记录

> **状态：全部完成（2026-10-22）。** 下列条目保留原始规格，并标注落地结果。

### 1. 护盾观察项修复（✅ 已完成）

- **落地**：`RespawnRules.h` 新增 `deathPenaltyClearsShield` / `shieldAfterDeathPenalty`
  纯函数；`PlayScene::beginDeath` 失去护盾术且层数归零时清空 `m_playerShield`，
  并输出日志「失去护盾术：护盾已清空」。
- **测试**：`tests/respawn_test.cpp` CASE 8（18 断言）覆盖清盾、仍有层数保留、
  非护盾技能不清盾、无损失不清盾、减速/冻结条不受影响。

- **问题**：死亡惩罚失去技能时，该技能对应的**主动效果**仍可能残留。
- **规则**：
  - 失去技能时**清空其对应的主动效果**——例如失去护盾术 → 立即清空当前护盾 buff；
  - 减速 / 冻结等**减益不受影响**（只清理由「被失去技能」产生的主动增益）。
- **测试**：补单测，落在 `respawn` 或 `attack_element` 套件（按实际归属选择）。
- **完成判据**：构造「持有护盾 → 死亡丢失护盾术 → 复活」场景，断言护盾值为 0；
  减益（减速 / 冻结）状态不被误清。
