## 一、批六 · 乙：复活点 + 死亡流 + 落水

### 1. 神龛（复活点）

- 草地神龛 =(3072,3072)，**默认激活（亮）**；
- 雪山神龛 =(6912,3072)，靠草地一侧；玩家进入约 64px 内提示「按 E 激活」（`bind_activate=E`，可改键）；
- 素材 `shrine.png` 两态（脚本产线）；
- 激活状态本局保持，R 重开重置。

### 2. 海洋开放与落水

- 玩家可入水（**怪物仍视为实心**）→ 进入 `Drowning` 状态：
  - 输入锁定；
  - 水花 `splash.png`（约 0.4s）；
  - 下沉淡出（约 0.5s）；
  - → 统一死亡处理。

### 3. 统一死亡处理（HP 归零与落水共用）

- **惩罚**：金币减半（向下取整）+ 等级 -1（最低 1），并丢失最近一次升级所得技能——升级历史栈出栈（法术层数 -1、归零则移除并停止施法），该级经验清零；
- **复活**：复活于距死亡地点最近的**已激活**复活点；
- **表现**：渐暗渐亮约 0.6s；复活后 2s 无敌（静默）。

### 4. 其他口径

- **GameOver 退役**：死亡不再进「游戏结束」；
- **R 键**：无触发场景（保留与否，乙批实现时报告说明）；
- **战绩结算口径**：死亡时静默比较写盘 + M 回菜单时比较写盘；旧「中途退出不计」退役。

### 5. 生成配平

- 怪物刷新采样改为「玩家周围 520~900px 环带」——要求 walkable、避水、激活区块内。

### 6. 测试

- 复活规则单测：最近激活点选择、惩罚数学、历史栈出栈。

## 二、批六 · 丙：怪物等级

- **等级来源**：由出生位置所在区决定——
  - 草地：1~20 级（`1 + 19 × 距草地复活点/最远距离`，±1 抖动）；
  - 雪山：21~30 级（离雪龛越远越高）。
- **数值缩放（初稿）**：生命 ×(1+10%/级)、伤害 ×(1+6%/级)、经验/金币同向放大（调平后定表）。
- **显示**：血条旁「Lv.n」。

### 丙批实现纪要（2026-10-19）

- **纯逻辑**：`game/MonsterLevel.h`（header-only）——区最远距离常量、
  `monsterLevelForSpawn`（分区/距离归一/±1 抖动/区间 clamp）、
  `scaledMonsterHp / scaledMonsterDamage / monsterXpValue / monsterCoinDrop`。
- **等级梯度最终值**：
  - 草地：`1 + round(19 x clamp(dist / 4344.464, 0, 1)) + jitter(-1..+1)`，
    神龛 (3072,3072)，最远角距离 `sqrt(3072²+3072²) = 4344.464`；
  - 雪山：`21 + round(9 x clamp(dist / 6191.814, 0, 1)) + jitter(-1..+1)`，
    神龛 (6912,3072)，最远角 `sqrt(5376²+3072²) = 6191.814`；
  - 最终 clamp 到区区间（1~20 / 21~30）。
- **缩放总表（初稿定案）**：
  - 生命 `round(基础 x (1+0.10 x (lv-1)))`：史莱姆 20/40/58/60/78、
    哥布林 30/60/87/90/117、骷髅 18/36/52/54/70（lv1/11/20/21/30）；
  - 伤害 `round(基础 x (1+0.06 x (lv-1)))`（默认基础 10）：lv1=10、
    lv11=16、lv21=22、lv30=27；移速沿用既有难度曲线不变；
  - 经验 `round(10 x (1+0.10 x (lv-1)))`：lv1=10、lv2=11、lv10=19、
    lv11=20、lv20=29、lv21=30、lv30=39；
  - 金币 = 变体基础 + `floor((lv-1)/10)`：1~10 级 +0、11~20 级 +1、
    21~30 级 +2（史莱姆/骷髅 1/2/3，哥布林 2/3/4）。
- **生成/显示**：等级在刷怪落点定稿时计算并存入 `Monster`（`spawnAt` 第三参），
  与玩家所在区无关；「怪物出现」日志改为
  「怪物出现（第 N 只，变体 Lv.n，区名，距玩家 xxx px）」；血条旁绘制
  屏幕空间「Lv.n」（16pt Font，满血无血条时仍显示）。
- **测试**：新增 `tests/monster_level_test.cpp`（88 断言，独立目标
  `monster_level_test`）；全量 16 套测试回归全绿。
- **冒烟**：①草地近神龛 Lv.2~6、西南远角 Lv.13~17 ②雪山 Lv.24/25
  （日志 + 雪地 Lv.25 血条截图）③Lv.24 哥布林剩余生命 74→49→24→0
  （4 刀）、受击 24 点（草地低等级 11~13）④经验 11~15 → 22~26 → 33/34；
  金币 1~2 → 2~3 → 3/4 ⑤暂停/商店/战斗/升级面板/退出码 0 不回归。
